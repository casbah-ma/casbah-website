## How to Download

Due to network restrictions in the sandboxed environment, these images need to be downloaded manually.

### Option 1: Manual Download
Visit each URL above in your browser and save the image to this folder with the corresponding filename.

### Option 2: Use the Download Script
A bash script has been created at `/tmp/download-stours-images.sh` that can be run in an environment with internet access to download all images at once.

## Note
The portfolio article at `/data/blogs/stours-rebranding-identity-modernization-dmc-morocco.md` references these image paths, so make sure to use the exact filenames listed above.
