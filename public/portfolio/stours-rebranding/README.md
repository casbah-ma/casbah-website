## How to Download

### Option 1: From GitHub Issue (Recommended)
1. Open the original GitHub issue
2. Right-click each image and select "Save image as..."
3. Save to this folder using the exact filenames above

### Option 2: From URLs
1. Open each GitHub URL in your browser
2. Right-click the image and "Save image as..."
3. Save to this folder using the exact filenames above

### Option 3: Download Script
A bash script is available at `/tmp/download-stours-images.sh` that can be run in an environment with internet access.
