1. Download each image from the GitHub URLs above
2. Save them with the exact filenames listed
3. Place them in `/public/portfolio/moroccan-lms/`
4. Verify the images are properly displayed in the article at `/blogs/moroccan-learning-management-system-digital-training-platform`

Note: The sandboxed build environment cannot access external URLs, so images must be manually downloaded and committed.
